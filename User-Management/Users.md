# Description
- コマンド→オプション（オプション効果、実際使った具体例）→*メモの順で並べる

# useradd
## options
### -r (--system)
- システムユーザーを作成（人が操作せず、Linux上のサービスなどを実行させるユーザー）
- 使う場面 : FastAPIの実行専用ユーザーとして、一般ユーザーと区別して管理したいとき

### -M (--no-create-home)
- ホームディレクトリを作成しない
- 使う場面 : クイズ用ユーザーはホームディレクトリで作業する必要がなく、不要なディレクトリを作成したくないとき

### -s (--shell)
- ログインシェルを指定
- 使う場面 : クイズ用ユーザーは対話的にログインする必要がないため、`/usr/sbin/nologin`を指定してログインを禁止したいとき

### -U (--user-group)
- ユーザーと同名のグループを作成
- 使う場面 : `webquiz`専用グループを作成し、他のユーザーやサービスと権限を分離して管理したいとき
